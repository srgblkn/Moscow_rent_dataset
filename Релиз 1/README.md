# EDA: Долгосрочная аренда квартир в Москве
## Релиз 1.0 — Разведочный анализ данных

**Задача:** Подготовить данные для модели оценки рыночной стоимости аренды  
**Регион:** Москва  

**Интерактивная аналитика по 20 000+ актуальным объявлениям с сервиса ЦИАН**

### Что внутри:
- Распределение цен (с лог-шкалой)
- Ценовые сегменты и их доли
- Топ станций метро по предложению
- Влияние площади, этажа, удалённости от метро
- Сравнение ЦАО vs остальная Москва
- Структура по комнатности и типу ремонта
- Глубокие выводы под каждым графиком

### Технологии:
- Python + Pandas
- Matplotlib + Seaborn
- Streamlit
